# 小星快递

一个温柔的解谜小游戏：帮小快递员“小星”把礼物送到动物朋友身边。为 Building Shanghai 制作，面向包括自闭症儿童在内的孩子。

- **规则只有三条**：走路 → 走到礼物上拿起来 → 走到朋友身边送给它。每位朋友永远只想要同一种礼物（小刺猬🍎、小兔🥕、小熊🍯、小猫🐟、小企鹅🧣、小猫头鹰🏮）。
- **两种模式**：简单（不限步数）/ 普通（有步数上限，按步数得 1–3 颗星；步数用完可退回、重来或换简单模式）。
- **前 3 关精心设计**：第 1 关是手把手教学，第 3 关学会“钥匙开小门”。
- **之后自动生成，可以一直玩**：关卡号决定地图（同一关每次都一样），每张图都由求解器验证能完成，并算出最少步数。新机关逐步出现，第一次出现前有讲解：
  - 第 6 关：推箱子进河搭桥（蘑菇森林）
  - 第 11 关：冰面滑行，用石头停下（冰雪山谷）
  - 第 16 关：星星传送门，走进一个、从另一个出来（星光夜晚）
  - 第 21 关：黄、蓝两把钥匙两扇门
- **四个世界**：阳光草地、蘑菇森林、冰雪山谷、星光夜晚，每 5 关轮换。
- **道具（可选的帮手）**：指路萤火虫（照亮整条路）、礼物磁铁（把礼物吸到手里）、加步鞋（普通模式 +5 步）。来自地图上的宝箱、每日礼物和每日挑战；不用也能过关，没有内购。
- **每日挑战**：每天一张新地图（同一天所有人相同），完成送一件道具，记录连续天数；断了也没有任何损失。
- **贴纸册**：15 张贴纸，只记录做到的好事（第一次三星、搭 5 座桥、认识所有朋友……）。
- **收集与成长**：选关界面显示每关星级；每关藏一颗可选的宝石；爱心 / 星星 / 宝石可以给小星解锁新帽子（衣橱）；朋友图鉴记录收到的礼物。
- **不会失败**：没有倒计时、没有扣分，可无限撤销/重来；“提示”会画出下一步的脚印。
- **感官友好**：声音、背景音乐（默认关闭）、动画、朗读可单独开关；有“休息一下”慢呼吸页面；跟随系统“减少动态效果”。
- **多种操作**：点地图自动走过去、滑动、键盘方向键 / WASD、屏幕方向键，或 micro:bit 倾斜控制。

## 运行

不需要安装依赖，需要 Node.js 18+：

```bash
node scripts/serve.mjs
```

打开 http://127.0.0.1:5173/ 。（不要直接双击 HTML，浏览器会限制模块加载。）

键盘：方向键/WASD 移动，Z 撤销，H 提示，I 道具，Esc 休息。

## micro:bit 控制器（可选）

| 动作 | 作用 |
| --- | --- |
| 倾斜板子 | 小星走一格 |
| A 键 | 提示；弹窗里相当于“确定 / 下一关” |
| B 键 | 撤销 |
| A+B 同时按 | 校准：把当前姿势设为“不倾斜”（开机时会自动校准一次） |

**校准**：连接后打开 micro:bit 面板（首页按钮，或游戏右上角绿色标记），会显示一个水平仪：蓝点在虚线圈里就不会走动。把板子放平点“校准”即可；容易误走就把灵敏度调低。旧版控制程序会显示“更新控制程序”按钮，点一下约 5 秒完成。

1. 第一次使用：把 `firmware/main.py` 烧录进 micro:bit（打开 https://python.microbit.org ，粘贴代码，点 “Send to micro:bit”）。如果板子上已经是 MicroPython，游戏里的“自动安装控制程序”按钮可以直接写入，不用编辑器。
2. 用电脑上的 **Chrome 或 Edge** 打开游戏，首页点“连接 micro:bit”，选择设备。
3. 连接成功后右上角会出现绿色的 “micro:bit” 标记。

如果提示端口被占用，关掉其他连着 micro:bit 的网页或编辑器再试。没有 micro:bit 也能完整地玩。

## 部署

线上地址：https://awmcedge-c0o6dnbs.edgeone.cool （EdgeOne Makers 项目 `awmcedge`）。

```bash
node scripts/deploy-edgeone.mjs
```

脚本只打包 `index.html`、`styles.css`、`src/`、`firmware/`、`promo/`（不含宣传片 mp4）。首次部署的网址带一次性的 `eo_token` 查询参数，访问后会种 3 小时有效期的 Cookie。

## 测试

```bash
node tests/run.js
```

覆盖规则、寻路、前 3 关可解、自动生成的第 4–80 关全部可解且机关真的用上、传送门 / 宝箱 / 磁铁、每日挑战可解、贴纸数据、普通模式星级规则，以及 micro:bit 协议（用模拟板子测试版本、校准、灵敏度）。

## 文件

- `src/game/`：规则（rules）、求解器（solver，用于提示和验证）、关卡生成器（generator）、数据（data）。
- `src/ui/`：SVG 美术（art）、棋盘渲染（board）、音效、朗读。
- `src/input/microbit.js`：Web Serial 连接、MicroPython 自动安装。
- `firmware/main.py`：micro:bit 控制程序。
- `promo/`：宣传片。`promo/xiaoxing-promo.mp4` 是成片（33MB，不进仓库，用 `scripts/render-promo.mjs` 重新渲染）；打开 http://127.0.0.1:5173/promo/ 可实时预览。
- `scripts/render-promo.mjs`、`scripts/promo-audio.mjs`：把宣传片逐帧渲染成 1080p60 视频并合成配乐（需要 ffmpeg 和本机 Chrome/Chromium）：`node scripts/render-promo.mjs`。
- `legacy/`：上一版《异轨》原型，保留备查。

## 说明

这是一个游戏，不是诊断或治疗工具。每个孩子的需要都不同，建议大人陪同试玩，观察孩子喜欢和不舒服的地方（可参考 `docs/PLAYTEST.md`）。进度只保存在当前浏览器里，没有账号、联网或数据收集。
