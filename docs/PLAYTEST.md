# 共同试玩记录模板

本模板用于了解游戏是否好玩、能否参与，不用于诊断、康复评估或给儿童打社交分数。

## 开始前

- 由参与者决定是否参加；涉及儿童时取得适当监护同意，同时尊重儿童本人的拒绝与退出。
- 先说明“不是考试，不必通关，可以休息、换角色或离开”。
- 询问当前偏好：声音、动态效果、文字大小、按键/触屏/实体板、独自或与熟悉的人一起。
- 不根据自闭症诊断预设阅读、语言、运动或解谜能力。不要求眼神接触、语音、拍手或模仿表情。
- 无需填写姓名、诊断、学校等身份信息；未经另行同意，不拍照、录像或录音。

## 一次约 10–15 分钟的试玩

1. 先让参与者看一眼地图，问“你觉得我们要做什么？”观察目标是否清楚。
2. 只解释移动、供电和撤销，允许自己探索；遇到问题先让参与者决定要不要提示。
3. 允许交换现场/调度角色，或单人控制两侧；不强迫双人或语言交流。
4. 体验暂停、地图标记与感官设置，让参与者知道自己能改变游戏条件。
5. 愿意时再试第二/三关，不以通关作为结束条件。出现不适、疲劳或退出意愿立即停止。

## 只记录与产品改进有关的现象

- 哪一步看不懂：目标、按钮名称、地图位置、供电规则还是下一步反馈？
- 哪些操作无法独立完成，原因是动作、文字、设备还是规则？
- 现场方与调度方是否都有决策，还是一人包办？等待是否无聊？
- 图标/文字标记够不够，是否需要更直接的表达方式？
- 哪个瞬间有趣，是否主动提出另一种方法、重玩或继续？
- 有无刺激过强、负担、疲劳或拒绝？当时的设置与情境是什么？
- 无 micro:bit 是否一样成立？实体控制是否真的更喜欢，而非成人觉得更有趣？

## 结束时可选问题

可通过说话、指选、文字、手势等参与者舒服的方式回答；不回答也可以。

- 哪个部分想再玩，哪个部分想删掉？
- 如果只改一个地方，你想改哪里？
- 下次想一个人玩，还是和谁一起玩？

## 产品判定

优先修复阻断参与与不适问题，再改善规则解释与两个角色的乐趣。不要把“配合成人指令完成任务”当成游戏有效，也不能由一两次试玩推导治疗效果。

当前项目尚未开展目标参与者共同试玩，本表是后续验证工具，不是已经完成的研究记录。
