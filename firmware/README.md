# micro:bit USB 控制器

## 设备与限制

- 固件仅使用 micro:bit V1 / V2 共有的 A/B 按钮、加速度计、LED 和 USB 串口；未用麦克风、扬声器或触摸徽标。
- 需要能传输数据的 USB 线，充电线不够。
- 网页端检查 `navigator.serial`。没有该接口时直接用键盘/触屏，不会缺少玩法。
- 网页必须来自可信上下文（本机 localhost / 127.0.0.1 或 HTTPS），并由你主动选择串口。无需蓝牙配对。
- **目前没有实物测试。** 下述步骤是待验证流程，不是已经兼容所有板子/电脑的承诺。

## 烧录

1. 接好板子，打开官方 [micro:bit Python 编辑器](https://python.microbit.org/)。
2. 将本目录 `main.py` 的内容放入编辑器，选择适合板子的固件/烧录方式。
3. 支持直接烧录时按编辑器流程选择设备；也可以下载 `.hex` 并复制到板子的 `MICROBIT` 磁盘。
4. 烧录完成后，关闭编辑器的串口监视器等占用串口的程序，再回到游戏。
5. 点击游戏右上方“连接 micro:bit” → “已烧录，选择设备” → 选择对应串口。

代码文件 `.py` 不是可直接拖进 MICROBIT 磁盘的 `.hex` 固件。本项目没有生成或实测特定板子的 HEX 文件。

## 操作

| 输入 | 游戏作用 | LED 辅助反馈 |
| --- | --- | --- |
| 向前/后/左/右倾斜 | 每次移动一格，持续倾斜会间隔重复 | 对应方向箭头 |
| 回到中立 | 停止发送移动消息 | 小方框 |
| A | 执行“现场操作”当前选中的动作 | 保留当前方向提示 |
| B | 选择下一个现场动作 | 以网页文字与高亮为准 |

将板子放平，轻轻倾斜即可，不需要摇晃。固件阈值为约 350mg，每 260ms 最多发送一次移动；网页另有节流。若实际装配方向不同，可在实物验证后修改轴向映射。

不适合倾斜操作时，关闭游戏设置中的“micro:bit 倾斜移动”。A/B 与屏幕操作仍可用。LED 不是唯一提示，可遮挡 LED，不影响游戏输入。

## 串口协议

115200 baud，UTF-8/ASCII，每行一条，以下是消息文本（每条结尾都带换行）：

```text
ORBIT|M|up
ORBIT|M|down
ORBIT|M|left
ORBIT|M|right
ORBIT|A
ORBIT|B
```

网页忽略未知/启动文本；缓冲上限为 64 字符，支持消息被拆分、CRLF、异常读流与主动断开。不会把串口内容当 JavaScript 执行。

暂停、设置、帮助或通关弹窗打开期间，网页不会执行硬件游戏动作。恢复后持续倾斜仍可能继续发送动作，建议先将板子放回中立位置。

## 常见问题

- **没有串口选项：** 检查浏览器接口支持、系统权限与数据线；仍可直接屏幕游玩。
- **连接失败或端口占用：** 关闭编辑器串口监视器、其他网页/应用中的串口连接后重试。
- **有连接但无输入：** 确认烧录的是本项目固件，串口波特率一致，倾斜控制没有关闭。
- **设备被拔掉：** 游戏保留局面，转用键鼠/触屏即可；再次连接需要主动点击授权。
