# 异轨 · Different Orbits

**一人走空间，一人改规则。** 一个不计时的中文合作设施解谜原型，为 Building Shanghai 制作。

让机器人把东侧的数据核心装车送回西侧，再亲自回到出口。现场方移动、搬运和操作物件，调度方分配共享电力、调整运输路线。单人也能操作全部控件。

## 运行

不需要安装依赖或构建。需要现代浏览器与 Node.js 18+：

```bash
node scripts/serve.mjs
```

打开 **http://127.0.0.1:5173/**。默认只监听本机；不要直接双击 HTML（浏览器会限制 ES modules）。在 Claude Code Browser 里使用 `.claude/launch.json` 的 `different-orbits` 配置。

当前机器可使用 `/usr/local/bin/node`。本机 Xcode Python 的预览进程遇到运行环境权限问题，因此项目提供了只用 Node 标准库的静态服务，无需额外安装服务器。

## 怎么玩

### 现场操作员 A

- 方向键 / WASD：每次移动一格。屏幕方向按钮有同等功能。
- 推动：站在空运输车或箱子的一侧，继续向它移动。
- E：执行当前附近的现场操作；也可直接点击“现场操作”里的按钮。
- 车只能在吊装短轨上推动；装载后必须通过货轨运输。
- Z：撤销上一步，机器人、货物、供电和电池一起恢复。

### 系统操作员 B

- 点击设备或按 1–4：将唯一的主电源接到所选设备。设备行末显示本关快捷键。
- 主电源只能供给一台设备；插入备用电池的设施可独立保持供电。
- 点击分轨 / R：切换运输路线。
- 货轨有电不等于自动发车：现场方需要走到车旁确认。

### 共同操作

- 数据核心和机器人都回到西侧才算完成，不要求快，不记录排名。
- 点击地图，或通过“选择标记对象”下拉框选中对象，再发送“这里供电 / 等一下 / 准备好了 / 需要帮助”。无需语音。
- P / Esc / “休息一下”：暂停。暂停时所有玩法输入（含硬件）被阻止。
- “提示”：逐级展开，不替你操作，不影响通关。
- 地图文字看不清时，点“放大地图”；放大后可以滚动查看。
- 单人模式不改变规则：你可以操作两侧。同屏双人时分工即可，随时可以交换角色，不需要登录或配对。

## 三个关卡

| 关卡 | 机制 | 配合重点 |
| --- | --- | --- |
| 断电中转站 | 共享电源、内部开启的维修通道 | 进入东侧、建立返回路线，再调电装载与发车 |
| 双路供电 | 可搬运电池、双桥、缓存分轨 | 决定为桥还是起重机留电，货物必须送到出口而不是缓存位 |
| 旁路计划 | 箱子撑门、电池保桥、两条货运路线 | 箱子与电池都是解法；直达线要求门开启，旁路线要求桥有电 |

遇到错误操作，局面不会改变，底部会解释原因。不能在机器人或箱子仍占用桥面时撤掉最后一份供电。箱子堵住单个门口时，第三关下方仍有人行通道。

已知完整解法存放在 `tests/solutions.js`，用于验证关卡确实可解，而不是只展示一张地图。

## micro:bit 可选控制器

没有设备也能完整通关。不会有硬件专属关卡、奖励或关键提示。

- 倾斜：移动，带中立死区与节流。
- A：执行附近交互。
- B：切换附近交互候选项，之后按 A 确认。
- LED：显示当前倾斜方向或中立小方框，是辅助提示，不是唯一信息来源。
- 可在设置中关闭倾斜，只保留按钮输入。
- 断线不会重开关卡，键鼠和触屏始终保留。

烧录、连接、协议和实物验收方法见 [firmware/README.md](firmware/README.md)。USB 网页接入依赖 Web Serial：以浏览器是否提供接口为准，通常需要支持它的桌面 Chrome / Edge、localhost/HTTPS 与主动授权。不承诺手机或所有浏览器支持。

**当前没有进行实体板烧录、LED、倾斜灵敏度或真实 USB 通信验收。** 固件完成 Python 语法检查；网页协议、取消授权、模拟读流与异常断开有自动测试，不能替代实物测试。

## 测试

规则、关卡、输入协议和设置测试：

```bash
node tests/run.js
```

启动预览后，打开 **http://127.0.0.1:5173/tests/**，另外运行浏览器端到端测试：通过实际页面控件完成六条解法，并检查暂停、撤销、提示、通关重玩、设置、键盘焦点、标记和地图放大。

浏览器测试在隔离 iframe 中运行，临时保存/恢复本地设置，不操作当前另一个游戏页面的局面。测试期间不建议同时在其他页面修改本地设置。

## 可访问性与隐私边界

- 默认音效关闭，无闪烁、无实时敌人、无强制倒计时。
- 标准/低刺激配置，减少动态效果、放大辅助文字可单独调节；尊重系统减少动态效果设置。
- 设备用文字、图形、线路样式共同表达，不单靠颜色。
- 有可见键盘焦点、触屏按钮、对象选择下拉框和文本状态提示。
- 只在当前浏览器存储设置和已完成关卡；当前关卡局面只保留在内存中，刷新会重开本关。暂停不丢进度。
- 无账号、摄像头、录音、诊断信息、联网聊天、追踪或外部字体/资源请求。
- 不宣称治疗或康复效果，也未取得无障碍认证。屏幕阅读器的完整空间导航体验仍需进一步共同设计与测试。
- 自闭症参与者的感官、运动、阅读和沟通需求不同，是否适合需要实际共同试玩，不能仅凭诊断或年龄判断。见 [试玩记录模板](docs/PLAYTEST.md)。

## 文件结构

- `src/game/`：纯规则、关卡数据、状态与撤销。
- `src/ui/`：SVG 地图、图标、本地设置；界面入口为 `src/main.js`。
- `src/input/`：键盘、屏幕方向按钮、Web Serial；统一转为游戏动作。
- `firmware/`：micro:bit MicroPython 固件与使用说明。
- `tests/`：可在 Node/浏览器运行的测试与页面端到端测试。
- `scripts/serve.mjs`：本地静态预览，不是生产后端。
